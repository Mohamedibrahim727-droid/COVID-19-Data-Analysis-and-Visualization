# COVID-19 Data Analysis and Visualization

## Project Overview

This project analyzes COVID-19 data using Python to explore the global impact of the pandemic through data cleaning, exploratory data analysis, and visualization.

The analysis focuses on confirmed cases, deaths, recoveries, trends over time, country comparisons, and relationships between different COVID-19 metrics.

## Objectives

- Understand and clean the COVID-19 dataset
- Perform Exploratory Data Analysis (EDA)
- Compare COVID-19 impact across countries
- Analyze global trends over time
- Create meaningful data visualizations
- Extract useful insights from the data

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed

- Dataset exploration and statistical summary
- Missing values and duplicate records analysis
- Global confirmed cases, deaths, and recoveries
- Top countries by confirmed cases and deaths
- Recovery and death rate analysis
- COVID-19 trends over time
- Confirmed cases vs. deaths analysis
- Correlation analysis
- Country impact classification

## Visualizations

The project includes different visualizations such as:

- Histograms
- Bar charts
- Line charts
- Scatter plots
- Correlation heatmaps
- Country impact comparisons

## Dataset

The project uses COVID-19 datasets containing country-level and time-series information.

The original dataset is included in the repository as `archive.zip`.
